# 美的集团与格力电器财务数据分析

## 一、项目简介

本项目选取美的集团与格力电器作为研究对象，对两家公司2021—2025年的财务数据进行整理与分析。

主要分析内容包括：

- 资产与负债结构分析
- 营业收入与利润变化分析
- 盈利能力分析
- 营运能力分析
- 偿债能力分析
- 杜邦分析

项目使用SQLite和SQL对财务数据进行整理、计算，并将最终分析结果整理至Excel，同时形成财务分析报告。

## 二、数据来源

项目所使用的财务数据来源于东方财富公开数据库，主要包括美的集团与格力电器2021—2025年的资产负债表和利润表数据。

## 五、主要财务指标

项目主要计算和比较以下指标：

### 盈利能力

- 毛利率
- 销售净利率
- 净资产收益率（ROE）

### 营运能力

- 总资产周转率

### 财务杠杆

- 权益乘数

### 偿债能力

- 资产负债率
- 流动比率
- 速动比率

## 七、主要结论
通过2021—2025年的财务数据比较可以发现：
- 美的集团营业收入和资产规模持续扩张，规模增长较为稳定。
- 格力电器整体盈利水平较高，毛利率和销售净利率均高于美的集团。
- 美的集团总资产周转率持续高于格力电器，资产运营效率表现较好。
- 两家公司资产负债率总体呈下降趋势，但期间存在年度波动，财务杠杆水平整体有所收敛。
- 两家公司在业务布局、盈利能力和资产运营效率等方面存在一定差异。
## 八、项目说明
本项目主要用于个人学习与作品集展示。
由于项目仅选取美的集团与格力电器两家公司进行比较，未进一步引入行业平均水平，因此相关结论主要用于两家公司之间的相对比较。
